# Security policy

This is research software that accompanies a book chapter. It is provided
as-is, without support or guaranteed fixes.

To report a vulnerability or an accidentally committed secret, use GitHub's
**private vulnerability reporting** (Security tab, "Report a vulnerability"),
not a public issue. Reports are handled on a best-effort basis.

Never commit API keys. If you find one in this repository's history, report it
privately so it can be revoked.
