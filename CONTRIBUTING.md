# Contributing

This repository accompanies a book chapter and is maintained on a best-effort
basis by a single author. **Issues and pull requests may go unanswered or be
closed without comment.** There is no support commitment.

You are encouraged to **fork** the repository and adapt it to your own
reviews, either by hand or with a coding agent (see `AGENTS.md`).

If you do open an issue, please include the version (tag) you used, your
Python version, and a minimal reproduction. Do not paste API keys or
copyrighted full texts.
